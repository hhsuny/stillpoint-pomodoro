# Stillpoint

一款电脑优先的个人番茄钟。专注计时、任务、坚持日历和每日总结都保存在当前浏览器中，不需要账号或云端服务。

## 使用

安装依赖并启动本地开发服务器：

```bash
npm install
npm run dev
```

正常计时为专注 25 分钟、短休息 5 分钟、每四个番茄后长休息 15 分钟。设置里的演示模式会缩短时长，适合快速检查流程。

## 数据

记录保存在浏览器本地存储中。同一台电脑使用同一个浏览器和网址时，刷新或重启后记录仍会保留。清除浏览器网站数据、换浏览器或更换网址后，记录不会自动跟随。

设置中可以导出 JSON 备份，也可以导入备份。迁移到新的网址（例如从 `localhost` 切换到 GitHub Pages）时，先在旧网址导出，再在新网址导入。GitHub 保存的是项目代码，不包含浏览器中的个人记录。

## 构建

```bash
npm run build
```

## 发布到 GitHub Pages

仓库使用 GitHub Actions 构建并发布 `dist`。首次发布时，在 GitHub 仓库的 **Settings → Pages** 将构建来源设为 **GitHub Actions**。之后推送到 `main` 分支会自动更新网站。

网站数据保存在当前浏览器和网址下。首次从 `localhost` 切换到 GitHub Pages 时，在旧网址导出 JSON 备份，再到线上网址导入；之后持续使用同一个线上网址和浏览器，记录会留在本机浏览器中。
